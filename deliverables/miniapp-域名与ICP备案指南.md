# 微信小程序上线：买域名 + ICP 备案 实操指南

> 适用对象：工器具管理系统微信小程序（AppID `wx43639b45152d6754`，后端独立端口 `3300`）
> 目标：拿到一个 **HTTPS + 已 ICP 备案** 的域名，让小程序正式发布后能调通后端
> 当前状态：后端已部署在腾讯云服务器 `82.156.62.59`，`nginx` 反代 `/api/` → `127.0.0.1:3300` 已就绪（见 `deploy/production/nginx.conf`）

---

## 一、为什么要做这两件事

微信小程序**正式发布**后，调用你自己的后端 API 必须满足两条硬规则：

1. `request` 合法域名必须是 **HTTPS**（不允许 HTTP、不允许纯 IP）
2. 该域名必须 **已完成 ICP 备案**

所以「买域名 + 备案」不是可选项，是发布的前置条件。开发调试阶段用 `http://82.156.62.59:3300` + 开发者工具「不校验合法域名」能跑，但**发版出去就不行**。

## 三、第一步：买域名（约 10 分钟，实名 1-3 天）

1. 登录 **腾讯云控制台** → 进入「域名注册」（`console.cloud.tencent.com/domain`）
2. 搜索并选购主域名，建议：
   - 后缀选 `.com`（约几十元/年，通用）或 `.cn`（更便宜，但必须国内实名）
   - 公司名/品牌名拼音或缩写，例如 `gtctools.com`
3. 下单付款（域名费按年收，建议一次买 2-3 年防忘续费）
4. **域名实名认证**（强制，否则不能备案）：
   - 企业：上传营业执照 + 填写统一社会信用代码
   - 个人：上传身份证
   - 审核 1-3 天，状态变「已实名」才能进入备案

> 子域规划：小程序 API 建议用独立子域 `api.gtctools.com`，与主站分开，便于以后单独管理证书和限流。

---

## 四、第二步：ICP 备案（核心，7-20 工作日）

备案**必须通过服务器接入商（腾讯云）提交**，不能在别处办。入口：腾讯云控制台 → 「网站备案」（`cloud.tencent.com/beian`）或 `beian.tencent.com`。

### 4.1 准备材料

| 主体类型 | 所需材料 |
|----------|----------|
| 企业 | 营业执照、法人身份证、应急手机号、邮箱、域名证书（实名后自动生成） |
| 个人 | 身份证、手机号、邮箱 |

> 备案省份必须与证件省份一致；一个备案号下可挂多个域名。

### 4.2 提交流程

1. 备案系统选「**新增网站**」→ 填写主体信息（企业/个人）
2. 填写网站信息：
   - 域名：`gtctools.com`（主域，子域 `api.` 自动包含）
   - 服务内容：选「**小程序 / 移动应用**」或「其他」
   - 服务器：选择你 `82.156.62.59` 对应的腾讯云实例
3. 下载核验单 → 签字/盖章 → 上传；用**腾讯云 App 扫码人脸核验**
4. 提交 → **腾讯云初审**（1-2 天，可能电话核实信息）
5. 初审通过 → 提交**省通信管理局**审核（**7-20 个工作日**）
6. 管局会发**短信核验**，24 小时内点链接确认（超时作废重来）
7. 审核通过 → 拿到备案号，格式如 `粤ICP备2026XXXXXX号`

### 4.3 关键坑（务必避开）

- 备案期间**服务器不能关停**、域名不能解析到境外，否则备案被驳回
- 备案主体要与**小程序主体一致**（企业小程序用企业备案，个人小程序用个人备案）
- 备案通过后必须**在网站底部悬挂备案号**（合规要求，虽然小程序里不一定展示）
- 管局短信核验**只有 24 小时**，留意手机短信别漏

## 五、第三步（备案通过后）：解析 + HTTPS + nginx

备案等待的 7-20 天里，下面的事可以**提前并行做**（除了解析需备案生效，证书和 nginx 配置都能先备好）。

### 5.1 域名解析（备案通过后操作）

腾讯云「DNS 解析 DNSPod」→ 添加记录：

| 主机记录 | 类型 | 值 | 说明 |
|----------|------|-----|------|
| `api` | A | `82.156.62.59` | 小程序 API 子域指向服务器 |

生效时间几分钟到几小时。

### 5.2 申请免费 SSL 证书

腾讯云「SSL 证书控制台」→ 申请**免费 DV 证书**（TrustAsia 或 Let's Encrypt），绑定 `api.gtctools.com`。
下载 Nginx 格式证书，上传到服务器 `/etc/nginx/ssl/api.gtctools.com/`。

> 也可用 `certbot` 签发 Let's Encrypt（你的 `nginx.conf` 注释里已预留该路径）。两者任选。

### 5.3 启用 nginx HTTPS（反代 3300）

把 `deploy/production/nginx.conf` 末尾注释的 HTTPS 段启用，并改成你的子域。关键片段：

```nginx
# HTTP → HTTPS 跳转
server {
    listen 80;
    server_name api.gtctools.com;
    return 301 https://$host$request_uri;
}

# HTTPS 主服务
server {
    listen 443 ssl;
    server_name api.gtctools.com;

    ssl_certificate     /etc/nginx/ssl/api.gtctools.com/fullchain.pem;
    ssl_certificate_key /etc/nginx/ssl/api.gtctools.com/privkey.pem;
    ssl_protocols       TLSv1.2 TLSv1.3;

    client_max_body_size 20M;

    # API 代理到小程序网关 3300（保持原有端口）
    location /api/ {
        proxy_pass http://127.0.0.1:3300;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 图片回显（如用到）
    location /uploads/ {
        alias /opt/tools-management/backend/uploads/;
        expires 30d;
    }
}
```

改完 `nginx -t` 校验，`systemctl reload nginx` 生效。

> ⚠️ 注意：你的 `nginx.conf` 原 HTTPS 模板写的是 `yourdomain.com`（主域）和 `/etc/letsencrypt/...` 路径，上线时务必改成 `api.gtctools.com` 和你实际的证书路径，并保持 `proxy_pass http://127.0.0.1:3300`（不要退回 3000）。

## 七、附带提醒：小程序自身也要备案

自 2023 年起，微信小程序**本身**也需在「微信公众平台 → 小程序备案」单独备案（与上面的 ICP 网站备案是两套流程）。这个在你能提审/发布时微信会引导你做，材料简单（主体信息 + 小程序信息），通常几天搞定。本文聚焦的是「API 域名备案」，别漏了小程序本体那一步。

## 八、时间总表与常见问答

### 时间线
| 阶段 | 耗时 | 能否并行 |
|------|------|----------|
| 买域名 + 实名 | 1-3 天 | — |
| 腾讯云初审 | 1-2 天 | 可并行准备证书/解析 |
| 管局审核 | 7-20 工作日 | 可并行做 nginx/SSL |
| 解析 + HTTPS 生效 | 几小时 | 备案通过后 |
| 微信后台配域名 | 当天 | 备案通过后 |

**总计约 2-4 周**，瓶颈是管局审核，提前并行能省一周。

### 常见问答
- **个人能备案吗？** 能，但小程序类目、微信支付会受限，**建议用企业主体**。
- **备案要花钱吗？** 腾讯云代办免费，只收域名费（几十元/年）。
- **必须在腾讯云备案吗？** 在哪买服务器就在哪家接入商备案；你服务器在腾讯云，就在腾讯云办。
- **已有域名在阿里云怎么办？** 可「接入备案」转入腾讯云，或直接用阿里云服务器（那就得把后端搬过去）。当前你服务器在腾讯云，域名建议直接在腾讯云买最省事。
- **备案期间小程序能先用着吗？** 能，用 `82.156.62.59:3300` + 开发者工具不校验域名先联调，等备案下来切正式域名。
