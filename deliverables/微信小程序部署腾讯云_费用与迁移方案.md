## 二、目标架构与关键结论

**架构结论（MigraQ 远端 + 微信/工信部官方文档）：**

```
用户 → CDN(/pc、/h5 静态前端，可选) → COS 存储(可选)
     → 小程序 wx.request → 轻量/CVM 后端(Node.js+PM2)
                          → 服务器本机数据存储(db.json + 每日备份)
                          → 上传图片存服务器磁盘(100–200G 内，可选 COS)
```

1. **后端形态**：推荐**轻量应用服务器 / CVM 有状态部署**（PM2 原样跑、零改造）。**不推荐云函数/微信云开发**——源系统是有状态常驻进程（fs 读写 db.json + 本地磁盘），上云函数等于数据层+存储层整体重写。【MigraQ远端】
2. **数据层（按你的要求）**：**不采购云数据库 MySQL**，数据存**服务器本机**（db.json + cron 每日全量备份，保留 30 天）；后续如需关系库，在服务器本机自装 MySQL 即可，不购买腾讯云数据库实例。
3. **图片**：存服务器本机磁盘（100–200G 容量内）；可选升级 COS + CDN。【MigraQ远端】
4. **静态前端**：PC/移动 H5 构建产物 → COS + CDN（可选）或由后端托管。
5. **小程序扫码**：web-view 内**无法调用 wx.scanCode**【MigraQ远端确认】，需原生页桥接；**核心扫码建议原生重写（Taro/uni-app）wx.scanCode 直调**。
6. **小程序主体**：**个人主体（免费）**——无需 300 元/年企业认证；类目受限、无微信支付，内部工器具管理场景足够。
7. **域名**：主体域名 **.cn** 为工信部批复后缀，**可正常 ICP 备案**；中国大陆节点服务器免费备案（7–20 工作日），备案通过后配置为小程序 request / uploadFile / downloadFile 合法域名（HTTPS）即可。

## 六、迁移工期与必要费用（不含人工）

### 两条迁移路线

| 维度 | 路线A：web-view 套壳（快） | 路线B：原生重写 Taro/uni-app（体验好） |
|---|---|---|
| 后端改造 | 小（Node.js+PM2 原样迁云） | 同 A |
| 前端改造 | 小（H5 复用 + 扫码桥接原生页） | 大（Vant4 页面全量重写） |
| 扫码 | ⚠️ web-view 内不能调 wx.scanCode，须原生页桥接 | ✅ wx.scanCode 直调 |
| 微信审核 | 业务域名白名单 + 备案，审核更严 | 正常审核 |
| **工期（日历天）** | **28–50 天（常规 4–7 周，最短 ~3 周）** | **50–85 天（常规 7–12 周）** |

### 必要迁移费用（去人工）

| 费用项 | 金额 |
|---|---|
| ICP 备案 | 免费 |
| 域名（.cn） | 首年 0–38 元（新用户），续费 ≈35–42 元/年 |
| 小程序主体 | **个人免费**（无 300 元/年认证） |
| 数据迁移 | db.json 原样保留在服务器本机 + cron 每日备份；**不采购云数据库**，无迁移费用 |
| 图片迁移 | uploads/ 随服务器迁移（或可选 coscli 同步 COS），≈0 元 |
| 云资源 | 见第五节两档月费 |

### 数据迁移要点

- **db.json**：服务器本机保留 + cron 每日全量备份（保留 30 天）；**不采购云数据库 MySQL**。
- **uploads/**：随服务器磁盘迁移；可选 `coscli` 增量同步到 COS（上传流量免费、请求费可忽略）。
- **割接窗口**：业务低峰（周末 00:00–04:00）；DNS TTL 提前降 60 秒；新老双跑观察 1–2 小时。
- **回滚**：DNS A 记录切回旧 IP（60 秒 TTL，1 分钟回退）；旧 db.json 保留只读快照；检查点：接口 200 / 扫码回调成功 / 图片可访问 / 数据条数一致。
