## 二、完整流程（5 步）

### Step 1: 注册域名（1 天）

1. 登录 [腾讯云域名注册](https://buy.cloud.tencent.com/domain)
2. 搜索想要的域名 → 加入购物车
3. 实名认证（个人/企业身份证）
4. 购买（.com 约 ¥55-70/年）

### Step 2: 实名认证（1-3 工作日）

- 腾讯云控制台 → 域名管理 → 提交实名材料
- 个人：身份证正反面
- 企业：营业执照 + 法人身份证
- 认证通过后域名才生效

### Step 3: ICP 备案（7-20 工作日）⚠️ 关键

> 国内服务器必须备案，否则 80/443 端口会被拦截

1. 腾讯云控制台 → **网站备案**
2. 下载"腾讯云网站备案"小程序（手机操作更方便）
3. 准备材料：
   - 身份证
   - 域名证书（域名管理页可下载）
   - 服务器信息（腾讯云自动填充）
   - 手机号 + 邮箱
4. 填写备案信息 → 人脸核验 → 提交审核
5. 腾讯云初审（1-2天）→ 工信部审核（5-20天）
6. **备案通过后**会收到短信 + 邮件通知

### Step 4: DNS 解析（即时生效）

备案通过后，配置域名指向服务器：

1. 腾讯云控制台 → **DNS 解析 DNSPod**
2. 添加记录：

| 记录类型 | 主机记录 | 记录值 | 说明 |
|----------|----------|--------|------|
| A | @ | 你的服务器公网IP | 主域名 |
| A | www | 你的服务器公网IP | www 子域名 |

3. 生效时间：通常几分钟内

### Step 5: 配置 SSL + 上线（10 分钟）

SSH 登录服务器，运行配置脚本：

```bash
cd /opt/tools-management
git pull origin main

# 配置域名 + Let's Encrypt 证书
sudo bash deploy/production/setup-domain.sh yourdomain.com
```

脚本会自动完成：
- ✅ 安装 Certbot
- ✅ 申请 Let's Encrypt SSL 证书（免费，90天有效期）
- ✅ 配置 Nginx HTTPS
- ✅ 设置证书自动续期（每天凌晨3点检查）

| 文件 | 用途 |
|------|------|

---

## 四、备案期间怎么办？

备案审核期间（7-20天），域名无法通过 80/443 访问，但可以：
- 继续用 **服务器 IP** 访问（当前方式不受影响）
- 用 **非标准端口**（如 8443）临时配置 HTTPS 测试扫码功能

备案通过后，运行 `setup-domain.sh` 即可切换到正式域名访问。

## 五、SSL 证书管理

| 操作 | 命令 |
|------|------|
| 查看证书状态 | `certbot certificates` |
| 手动续期测试 | `certbot renew --dry-run` |
| 立即续期 | `certbot renew` |
| 查看续期计划任务 | `crontab -l \| grep certbot` |

证书有效期 90 天，自动续期已配置，无需手动操作。
